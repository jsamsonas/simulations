# The Mill Town Game

A six-round classroom simulation of a New England town facing the Industrial Revolution, 1823–1855. Students govern the town as its Board of Selectmen (later Mayor and Aldermen) and decide on water rights, zoning, taxes, public works, strikes, immigration, and public health, while four neighboring towns follow other strategies.

Open `index.html` in any modern browser, or publish this folder with GitHub Pages. Each student's progress saves in their own browser.
